# Nexus

> AI-powered knowledge engine.

---

## 📖 About

Nexus is an AI-powered search engine that can search across:

- 🌐 Websites
- 📄 Documents (PDF, DOCX, TXT)
- 💻 GitHub repositories

Instead of just matching keywords, Nexus will understand what the user is looking for using semantic search and AI.

---

## 🚀 Planned Features

- User Authentication
- Website Crawler
- GitHub Repository Indexing
- PDF Upload & Search
- Semantic Search
- AI Chat Assistant
- Search History
- Dashboard
